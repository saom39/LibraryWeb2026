系统说明

本系统基于 Java Servlet + JDBC 开发，服务端使用自研的轻量级 ORM 工具完成对象与数据表的映射， 前端采用 HTML + CSS + Vue + jQuery + Axios 构建。页面与接口打包在同一个 war 中， 由本机 Tomcat 统一提供，未使用 JSP，也未采用前后端分离部署。数据存储于 MySQL 的 libraryms 库。
